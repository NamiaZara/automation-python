# automation-python
# Selenium Automation Project

This project is an automation testing suite using **Selenium WebDriver** and **pytest** for functional testing of a sample web application (https://www.saucedemo.com/). The project follows the **Page Object Model (POM)** design pattern to organize the test scripts, page classes, and utilities.

## Project Structure

/SQA_Automation_Project 
│── /pages # Page Object Model (POM) classes (e.g., Login, add_to_cart) 
│── /tests # Test scripts for different functionalities 
│── requirements.txt # Python versuin anf sekenium version 
│── README.md # Documentation for the project 
│── .gitignore

## Prerequisites

To run the tests, you need the following:

- **Python 3.x** (preferably Python 3.7 or above)
- **Selenium** WebDriver (for browser automation)
- **pytest** (for running tests)
- WebDriver for your browser (ChromeDriver, GeckoDriver, etc.)
